Coding at home?

Families can install Python for free (Windows, Mac or Linux) or use a website that needs no install. Python at Home: setup guide

For the teacher

  • Each guide is a separate HTML file. They open in any browser and work offline. No internet is needed.
  • Typing only: pupils cannot select, copy or drag the code on the page (Ctrl+C, right click and drag are blocked, with a pop-up message). A pupil who really wants to could bypass it with browser developer tools, so it is a nudge, not a lock.
  • Every step is built from real turtle code. I ran each step's cumulative program with Python's turtle module and embedded the true picture, so what pupils see beside each step is what IDLE will draw. All 12 final programs run with no errors.
  • Steps are additive: new lines always go at the end of the file. The coloured bars show indents. IDLE keeps the indent of the line above and adds one after a colon, so pupils are told not to type spaces and to use Backspace to go back out. Each step says when this matters.
  • Each pupil's progress ticks are saved in their own browser, so refreshing the page does not lose them.
  • New commands beyond L01 to L06 appear in a green New box as they are first used: fillcolor, begin_fill, goto, circle, dot, setheading, write and lists in a for loop. L08 teaches fill properly, so the Easy pictures use it gently.
  • The guides use only the lesson's pattern import turtle and t = turtle. Pupils save as 7_<picture>.py in OneDrive, Documents, Computing, Year 7, Python.
  • Suggested use: Easy pictures for anyone who needs a confidence boost or finishes the robot early. Medium and Hard for pupils who want more of a challenge.
