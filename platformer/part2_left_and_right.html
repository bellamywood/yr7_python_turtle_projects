In this part

Make the blue square move with the arrow keys.

You will learn: A function (def). Moving with setx. Connecting a key to a function.

Open your own file 7_keyquest.py in IDLE. You carry on from the last part.

My game does not work. What do I check?
  • Nothing moves at all: did you click on the game window once? The window must be clicked before it hears the keys.
  • Red error text in the IDLE Shell: read the last line. It says what is wrong and which line.
  • NameError: a spelling mistake, like playre or go_rigth. Check capitals: everything here is lower case.
  • IndentationError: the bars are wrong. Match the bars on this page.
  • SyntaxError: a missing bracket ), quote " or colon :. Check the line IDLE shows, and the one above it.
  • The game window closes at once: run it from IDLE with F5. Do not double-click the file.
  • You typed in the wrong place: your code must be under a PART line and above the line that says Do not type below this line.
  • Still stuck? Read your lines out loud to a partner. Then ask your teacher.

1Make a function called go_right

A function is a list of instructions with a name. This one moves the blue square 12 to the right.

New idea (read this, do not type it):
  • def go_right():  Makes a function. A function is a list of instructions with a name. It only runs when something calls it.
  • player.setx(player.xcor() + 12)  xcor() is how far across the player is. setx() puts the player at a new x. This moves the player 12 to the right.
Where to type: find the line that says PART 2: LEFT AND RIGHT (Ctrl and F helps). Click at the very end of that line and press Enter. Type your lines under it.
Type these 2 lines:
def go_right():player.setx(player.xcor() + 12)
Each bar is one indent. IDLE adds one for you after a colon. Do not type the spaces. Press Backspace to remove a bar.
Test it:
  • Press F5. Click on the game window. Press the Right arrow.
  • Nothing happens yet. That is right: a function only runs when something calls it.

2Connect the Right arrow key

Now tell the window: when the Right arrow is pressed, run go_right.

New idea (read this, do not type it):
  • screen.onkeypress(go_right, "Right")  When the Right arrow key is pressed, run go_right. There are no brackets after go_right here.
  • screen.listen()  Tells the window to listen to the keyboard. You must also click on the game window once.
Where to type: click at the end of the last line you typed in this part. Press Enter. If the cursor is indented, press Backspace until it is at the left edge. Then type.
Type these 2 lines:
screen.onkeypress(go_right, "Right")screen.listen()
Test it:
  • Press F5. Click on the game window once.
  • Hold the Right arrow. The blue square moves right!
Tip: No brackets after go_right in the onkeypress line. With brackets, the function would run straight away instead of when you press the key.
What you should see:

3Do the same for the left

Copy the idea. This time the number is minus 12, and the key is Left.

Type these 3 lines:
def go_left():player.setx(player.xcor() - 12)screen.onkeypress(go_left, "Left")
