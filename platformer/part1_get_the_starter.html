In this part

Open the starter game and run it. The world is built for you. Nothing moves yet.

You will learn: Open a file in IDLE. Run a program. What is in the game.

My game does not work. What do I check?
  • Nothing moves at all: did you click on the game window once? The window must be clicked before it hears the keys.
  • Red error text in the IDLE Shell: read the last line. It says what is wrong and which line.
  • NameError: a spelling mistake, like playre or go_rigth. Check capitals: everything here is lower case.
  • IndentationError: the bars are wrong. Match the bars on this page.
  • SyntaxError: a missing bracket ), quote " or colon :. Check the line IDLE shows, and the one above it.
  • The game window closes at once: run it from IDLE with F5. Do not double-click the file.
  • You typed in the wrong place: your code must be under a PART line and above the line that says Do not type below this line.
  • Still stuck? Read your lines out loud to a partner. Then ask your teacher.

1Get the starter file

The starter has the whole world and the game engine in it. You do not type it. Pick one way to get it.

  1. Best: click the button below to download key_quest_starter.py. It usually goes into your Downloads folder.
  2. Cannot download? Open the box called Show the starter code below, click the Copy button, then in IDLE choose File, New File and paste. Save it as 7_keyquest.py.

# KEY QUEST starter. Get the key, then open the door. # You do NOT need to understand the code above the PART lines. # You only type your own code under the PART lines. import turtle screen = turtle.Screen() screen.setup(800, 600) screen.bgcolor("skyblue") screen.title("Key Quest") screen.tracer(0) screen.register_shape("key", ((0, -15), (4.2, -13.2), (6, -9), (4.2, -4.8), (2, -3), (2, 14), (-6, 14), (-6, 11), (-2, 11), (-2, 8), (-5, 8), (-5, 5), (-2, 5), (-2, -3), (-4.2, -4.8), (-6, -9), (-4.2, -13.2))) # ---------- THE WORLD (already built for you) ---------- platforms = [] coins = [] def make_platform(x, y, w, h): p = turtle.Turtle() p.shape("square") p.color("black", "forestgreen") p.shapesize(h / 20, w / 20) p.penup() p.goto(x, y) p.half_w = w / 2 p.top = y + h / 2 platforms.append(p) def make_coin(x, y): c = turtle.Turtle() c.shape("circle") c.color("darkorange", "gold") c.shapesize(0.7) c.penup() c.goto(x, y) coins.append(c) make_platform(0, -250, 800, 40) make_platform(-250, -160, 140, 20) make_platform(-60, -80, 140, 20) make_platform(130, 0, 140, 20) make_platform(300, 80, 140, 20) make_coin(-250, -120) make_coin(-60, -40) make_coin(130, 40) player = turtle.Turtle() player.shape("square") player.color("black", "royalblue") player.penup() player.goto(-350, -220) player.vy = 0 player.on_ground = False player.has_key = False player.score = 0 key = turtle.Turtle() key.shape("key") key.color("darkgoldenrod", "gold") key.penup() key.shapesize(1.4) key.goto(300, 114) door = turtle.Turtle() door.shape("square") door.color("black", "firebrick") door.shapesize(3, 2) door.penup() door.goto(340, -200) writer = turtle.Turtle() writer.hideturtle() writer.penup() writer.goto(0, 240) def say(message): writer.clear() writer.write(message, align="center", font=("Arial", 22, "bold")) # ---------- THE GAME ENGINE (already built for you) ---------- # These do nothing until YOU replace them in the PART steps. def check_key(): pass def check_door(): pass def check_coins(): pass def game_loop(): player.vy = player.vy - 0.8 player.sety(player.ycor() + player.vy) player.on_ground = False for p in platforms: feet = player.ycor() - 10 was = feet - player.vy if player.vy <= 0 and was >= p.top - 1 and feet <= p.top and abs(player.xcor() - p.xcor()) < p.half_w + 8: player.sety(p.top + 10) player.vy = 0 player.on_ground = True if player.xcor() < -390: player.setx(-390) if player.xcor() > 390: player.setx(390) if player.ycor() < -320: player.goto(-350, -220) player.vy = 0 check_key() check_door() check_coins() screen.update() screen.ontimer(game_loop, 20) # 2Open it in IDLE and save your own copy

Always work on your own copy. Then the starter stays safe if something goes wrong.

  1. Open IDLE. Click File, then Open. Go to Downloads, find key_quest_starter.py and open it.
  2. Click File, then Save As. Go to your Year 7 Python folder (in school: OneDrive, your name, Documents, Computing, Year 7, Python). Type the name 7_keyquest.py and click Save.
  3. From now on, only ever open and edit 7_keyquest.py.

3Run it

Press F5 to run the starter. You should see the game world.

  1. Press F5. A window called Key Quest opens.
  2. Click on the Key Quest window once. Press the arrow keys and the space bar.
  3. Nothing moves. That is right! You are about to make it move.

4Find the PART lines

The starter has lines that begin with a # and say PART 2, PART 3 and so on. You will type your code under them.

  1. In IDLE, press Ctrl and F. Type PART 2 and press Enter. IDLE jumps to that line.
  2. Look down the file. You can see PART 2, PART 3, PART 4, PART 5, PART 6 and PART 7, one after the other.
  3. You only ever type under a PART line. Never change the lines above them.
  4. The last PART line says Do not type below this line. That is where the game starts.
