Before you start: how to type

  • You must type every line yourself. Copy and paste is switched off on this page on purpose. Typing is how you learn.
  • Open IDLE. File, New File. Press Ctrl and S and save it as 7_dog.py.
  • Type the lines of each step at the end of your file. Do not type the line numbers.
  • Turn on line numbers in IDLE: Options, Show Line Numbers. Then you can match your lines to this page.
  • Only type the code in the white boxes with line numbers. The green New idea boxes are for reading.
  • Copy every letter, bracket and quote exactly. Use straight quotes "like this". Python is fussy about capital letters. 0 is the number zero, not the letter O.
  • After each step press F5. Check your picture. Then tick the box and move on.
My program has an error. What do I check?
  • SyntaxError: a missing bracket ), a missing quote " or a missing colon :. Look at the line IDLE highlights, and the line above it.
  • IndentationError: the bars are wrong. Lines inside a loop must have the same number of bars as the picture on this page.
  • NameError or AttributeError: a spelling mistake, like t.forwad or t.Goto. Everything is lower case.
  • AttributeError: ... has no attribute 'fillcolour': Python commands use the American spelling color, so it is t.fillcolor and t.pencolor. Never colour.
  • bad color name: a colour is spelt wrongly or has no quotes. Use the exact name from the page.
  • Nothing happens or the turtle window is blank: did you save and press F5? Is import turtle on line 1 and t = turtle on line 2?
  • Picture looks wrong but no error? Compare each number with this page. One wrong number moves a shape.
  • Still stuck? Read the line out loud to your partner, then ask your teacher.

2The four legs

One loop draws all four legs. Inside it, a second loop draws each rectangle. i moves each leg 50 along.

New idea (just read this, do not type it):
  • a loop inside a loop  The inner loop runs fully every time the outer loop goes round once.
  • -130 + i * 40  i counts 0, 1, 2 ... so this moves each window 40 further along.
Type these 12 lines at the end of your file (lines 6 to 17):
6t.fillcolor("sienna")7for i in range(4):8t.penup()9t.goto(-120 + i * 50, -30)10t.pendown()11t.begin_fill()12for j in range(2):13t.forward(30)14t.right(90)15t.forward(90)16t.right(90)17t.end_fill()
Each bar is one indent. IDLE adds one for you when you press Enter after a colon. Do not type the spaces. Press Backspace to remove a bar.
Tip: Press Backspace once after the inner loop, so end_fill lines up with t.penup(). Press it again when the outer loop is finished.
Press F5. You should see:

The bright part is new. The faded part was there before.

Check: your last line of code should be line 17. (If you added empty lines, your number will be a bit bigger. That is fine.)

4The tail

A thick curved line. pensize(12) makes it fat. circle with a minus radius curves it up and over.

New idea (just read this, do not type it):
  • t.circle(-40, 90)  A minus radius curves to the RIGHT instead of to the left.
  • t.setheading(90)  Turns the turtle to face a direction. 0 is right, 90 is up, 180 is left, 270 is down.
