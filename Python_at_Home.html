Two ways to code at home

A. Install Python (best)

This is the same IDLE that we use in school. Your files stay on your own computer. It works with no internet once it is installed.

Works on Windows, Mac and Linux. Needs a computer you are allowed to install programs on.

Go to the install steps

B. Use a website (nothing to install)

Good for Chromebooks, school-managed laptops, or a quick try. You type code in your web browser and the picture appears on the page.

It can be a little different from IDLE. Read the notes on safety first.

Go to the online options

For parents: before you start

  • Python is free. You never need to pay, and you do not need to give a card number or an email address to install it.
  • Download Python only from python.org, or from your computer's own store or package manager. Do not use other websites that offer "Python downloads".
  • A parent or carer should do the install. It only takes a few minutes.
  • If a website asks for a name, an email address or a date of birth, stop and check the age rules together first. A pupil can do everything in these guides without an account.
  • The school picture guides work the same at home. Type every line yourself. Do not copy and paste: typing is how you learn.

A. Install Python

Choose your computer. We have picked the one we think you are using, but you can change it.

Windows 10 or 11

  1. Open your web browser and go to python.org/downloads.
  2. Click the big yellow Download button for Windows. A file called the Python install manager downloads. (The Microsoft Store has it too: search for Python install manager and click Install.)
  3. Open the downloaded file and click Install. You may be asked to add a folder to your PATH. This is optional: you can say no.
  4. Wait until it says it has finished. The install manager may ask to install the latest Python runtime. Say yes.
  5. Open IDLE: press the Windows key, type IDLE and click it. Cannot find it? Press the Windows key, type cmd and press Enter. In the black window type py -m idleliband press Enter. A window called IDLE Shell opens. This is where Python lives.
If IDLE still does not open: restart the computer and try again. Still no IDLE? Use the online options below and tell your teacher.

Mac

  1. Open Safari or Chrome and go to python.org/downloads.
  2. Click the yellow Download button for macOS. A file ending in .pkg downloads.
  3. Double-click the .pkg file. Click Continue through Read Me and License, then Agree and Install. A parent may need to type the Mac password.
  4. When the install finishes, a Python folder window opens. Double-click Install Certificates.command once. A black window opens and closes by itself. This helps Python stay safe online.
  5. Open Finder, click Applications, then open the folder called Python 3.15 (the number may be a little different). Double-click IDLE. The IDLE Shell window opens.
Tip: drag IDLE to the Dock so it is easy to find next time.

Linux (Ubuntu, Debian, Mint, Raspberry Pi OS)

Most Linux computers already have Python. You need to add IDLE and Tk (the part that draws the turtle window). A parent should type these in a Terminal window.

  1. Open Terminal. Type this and press Enter. Type your password if asked (nothing shows as you type):sudo apt update
  2. Install Python, IDLE and Tk:sudo apt install python3 python3-tk idle3
  3. Open IDLE by typing this in the Terminal, or find IDLE in your applications menu:idle3

Fedora: sudo dnf install python3 python3-tkinter python3-idle, then run idle3 or idle.

Chromebook? Many school Chromebooks have Linux turned off. If yours is your own, turn on Linux development environment in Settings, then follow the Linux steps above. If you cannot, use the online options below.

Now try it (all computers)

  1. In the IDLE Shell window click File, then New File. A blank window opens. This is where we write code.
  2. Type these lines. Type, do not paste.
    import turtle t = turtle t.forward(100) t.right(90) t.forward(100)
  3. Press Ctrl and S (Mac: Command and S). Save it in a folder you can find, called 7_test.py.
  4. Press F5 (on some Macs and laptops: fn and F5, or Run, then Run Module). A Python Turtle Graphics window opens and an arrow draws an L shape. It works!

Now open the Python Turtle picture guides and make a Robot.

It did not work. What do I check?
  • No turtle window: did you press F5 in the file window (the blank one you typed in), not the Shell?
  • Red error message: check spelling, capital letters, brackets and quotes. Python uses the American spelling, so t.fillcolor, never fillcolour.
  • "No module named tkinter" or "_tkinter": on Linux, install Tk: sudo apt install python3-tk. On Windows or Mac, run the python.org installer again.
  • Window disappears at once: run the file from IDLE with F5. Double-clicking a .py file closes the window the moment it finishes.
  • Still stuck? Take a photo of the red message and show your teacher.

Safety notes for online editors

  • Pick a site that works with no account. If it asks for a name, email or date of birth, ask a parent and check the age rules.
  • Never type your full name, address, school or passwords into code or into the site.
  • Do not click ads or "download" buttons. You never need to download anything to run code in the page.
  • Many free sites do not save your work when you close the page. Copy your finished code into a file or a notebook so you do not lose it.
  • A website is not exactly the same as IDLE. If something works in IDLE but not online, it is usually the website.

Quick answers

  • Is Python safe? Yes, when it comes from python.org. It is free, open source software used all over the world.
  • Does it cost anything? No.
  • Which version? The newest Python 3 on python.org (3.15 when this guide was checked). Any recent Python 3 works for the school picture guides.
